文本输入

hierarchy 模式操作选中的实时元素；remote 模式操作当前焦点。设备操作后需手动刷新层级。

模式说明

hierarchy
一次获取画面和节点树；本地拾取与快照搜索不会重新读取设备。
color
无损取色、放大镜、HEX / RGB / HSB / OpenCV HSV、坐标微调和多点记录。
remote
scrcpy H.264 远程画面；鼠标按下/拖动/松开直接触摸，触摸板双指滚动转为设备滚动。
区域截图
拖动选区或八个边角调整，也可输入坐标或用方向键微调；保存成功后自动清除。

工作区

设备在左，属性和节点树在右。两条分隔线均可拖动。

截图文件

当前目录文件；删除会移除磁盘文件。复制后可在本机文件管理器使用系统粘贴快捷键粘贴 PNG。

截图后在此预览，无需打开保存文件夹

录屏文件

侧栏圆形按钮开始 / 停止录屏。录制 scrcpy 原始画面，不含节点框；无音频 WebM。切换模式或断开会停止并保存。关闭页面前请等待保存完成。
